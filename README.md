# 屿 · 情绪小岛

> 一片只属于你的柔软角落 —— 记录情绪、看见规律、慢慢治愈。

一款完全运行在浏览器里的个人情绪 + 饮食记录工具，
**零依赖、零后端、零账号**，所有数据都只保存在你自己的浏览器里。

## 它能做什么

- 🌱 **记一笔** 情绪：日期、几点开始难过、持续时长、天气、难过程度、变坏原因、怎么慢慢变好、当时的感悟
- 📖 **时光集** 按 **月视图 / 周视图 / 列表** 三种模式回看
- 🔮 **心象图谱** 自动分析：低谷时刻分布、持续时长趋势、什么最容易弄坏心情、什么最能哄好你
- 🕊️ **疗愈室** 本地温柔观察 + 可选 AI 深度分析（可接 DeepSeek / OpenAI 等）
- 🍱 **三餐记录** 每顿吃了什么、是否按时吃、零食 —— 在日历点任意一天就能补录
- 📦 **数据导入 / 导出** 一键备份 / 还原
- 🎨 治愈系视觉（奶油暖底 + 桃粉 + 鼠尾草绿，漂浮云朵）

## 如何使用

### 本地（推荐，完全私密）

直接双击 `index.html` 即可在浏览器打开。数据保存在浏览器 `localStorage`，
**不会**上传到任何地方，关掉页面数据也还在。

### 静态部署

整个项目是纯静态文件，可以部署到任何静态托管：

- **GitHub Pages**（仓库 Settings → Pages → 选择 main 分支）
- **AtomGit Pages**
- **CloudStudio**、Vercel、Netlify、Gitee Pages 等

部署后用浏览器打开链接就行。
**注意**：localStorage 是按「浏览器 + 域名」隔离的，换台设备 / 换浏览器数据是空的，
旧设备的数据可以用「导出备份」JSON，新设备再「导入备份」。

## 可选：接 AI 深度分析

在「⚙ 设置与数据」里填一个 OpenAI 兼容接口：

- 默认填的是 DeepSeek 的格式：`https://api.deepseek.com/v1` + `deepseek-chat`
- 也可以填 Kimi、通义千问、Chat Completions 兼容的其他服务
- **API Key 只存本机浏览器**，分析时才发送给模型

> ⚠️ 由于浏览器跨域限制，少数接口可能无法直接调用；
> 若一直失败，本地的「小岛观察」分析不依赖网络，始终可用。

## 数据模型（localStorage key）

| Key | 内容 |
| --- | --- |
| `mood_island_records_v1` | 情绪记录数组 |
| `mood_island_meals_v1` | 三餐按日期聚合（`{'YYYY-MM-DD': {b, l, d, sn}}`） |
| `mood_island_settings_v1` | 用户设置（接口配置、自定义变坏原因等） |

## 隐私

- 100% 离线可用
- 除非你主动接 AI 分析，否则数据**永不离开你的设备**
- AI 调用只在你点「深度 AI 陪聊分析」时，把当次请求的记录摘要发到你配置的那个 API
